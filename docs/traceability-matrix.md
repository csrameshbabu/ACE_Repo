## Evidence completeness rules

Each pipeline run should publish a manifest containing commit SHA, workflow URL/run ID, Java/Maven versions, test counts, test report paths, dataset versions and SHA-256 hashes, k6/device/security run IDs where applicable, trace sample references, decision owner, exceptions, and timestamps. Reports must be redacted before retention. A missing or empty artifact is a failed evidence gate, not a pass.

## Linking new requirements

Assign a stable ID; identify the business outcome and accountable owner; record risk and deterministic control; name the test and synthetic dataset; publish machine-readable result and trace; define threshold and blocking behavior; record residual risk, approver, and expiry. Never use an AI-generated risk score to waive mandatory controls.
