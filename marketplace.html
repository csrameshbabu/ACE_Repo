Agent Plugin

ACE Digital Banking Quality

Risk-based quality engineering and AI assurance workflows for a synthetic digital-banking reference project.

About the agent

ACE Quality Engineer helps review and improve API contracts, transfer controls, AI assurance, observability, test evidence, and release governance while preserving synthetic-data and approval boundaries.

  • API and contract quality
  • AI and agentic assurance
  • Release evidence reviews

Installation instructions

  1. Open VS Code and run Chat: Open Customizations from the Command Palette.
  2. Open Plugins, then select + next to User or Workspace.
  3. Choose Install Plugin from Source.
  4. Enter the repository URL below and confirm installation.
https://github.com/csrameshbabu/ACE_Repo

Start a new Copilot chat and select ACE Quality Engineer. This is a Copilot Agent Plugin installation, not a traditional VS Code Marketplace extension.
